# Shadowing practice

Тренажёр шэдоуинга: студент слушает фразу из лекции, повторяет её и получает разбор по четырём линиям – мелодия (интонация), звуки, ритм, ударение – с подсветкой каждого слова. Всё работает в браузере, записи никуда не отправляются.

## Как это устроено

| Что проверяется | Чем | Как |
|---|---|---|
| Правильные ли слова | Whisper base.en (Transformers.js) | Распознанный текст выравнивается с целевой фразой по словам: пропуски, замены, лишние слова |
| Качество произношения | wav2vec2-base-960h (CTC, без языковой модели) | Принудительное выравнивание целевой фразы по буквам (алгоритм Витерби, как `torchaudio.forced_align`). Для каждого слова – уверенность модели в его звуках, откалиброванная по диктору: если диктор даёт 0,9, а студент 0,4, слово помечается. Плюс «что услышала модель» по звукам, без подсказки словаря |
| Интонация | Собственный трекер YIN (F0 каждые 10 мс) | Высота тона переводится в полутоны относительно средней высоты своего голоса (мужской и женский голос сравнимы). Запись студента растягивается на временную ось диктора по границам слов, и кривые сравниваются точка в точку: среднее отклонение в полутонах, форма, ядерный тон (fall, rise, fall-rise, rise-fall), движение тона на каждом слове, диапазон, слово с самым высоким тоном |
| Ритм | Границы слов из выравнивания | Темп, относительная длина каждого слова, совпадение пауз |
| Ударение | Энергия + высота тона | Какое слово выделено сильнее всего и где пик внутри длинных слов |

Итоговый балл: мелодия 40 %, звуки 30 %, ритм 15 %, ударение 15 %. Если мелодия заметно отличается, итог не может быть выше оценки мелодии больше чем на 20 баллов. Если не хватает слов, итог ограничен 45.

Почему старая версия «плохо считывала»: она сравнивала записи целиком вместе с тишиной в начале и конце, растягивала их равномерно, а Whisper сам по себе «додумывает» ожидаемые слова. Теперь тишина обрезается, сравнение идёт по словам, а произношение оценивает акустическая модель без языковой.

## Структура

```
index.html            страница
css/style.css         оформление (корпоративные цвета)
data/phrases.json     лекция, фразы, модели, строгость
js/app.js             логика страницы
js/worker.js          нейросети в отдельном потоке (Transformers.js)
js/pitch.js           YIN и очистка контура
js/align.js           CTC-выравнивание, сравнение слов
js/analysis.js        анализ одной записи
js/scoring.js         сравнение и тексты обратной связи
js/charts.js          мелодическая линия, осциллограмма, спектрограмма
js/audio.js           запись с микрофона, 16 кГц
tests/run-tests.mjs   тесты на синтетических сигналах (npm test)
```

## Публикация на GitHub Pages

1. Загрузите содержимое папки в репозиторий (например, `Oletol/shadow`).
2. Settings – Pages – Source: Deploy from a branch, ветка `main`, папка `/ (root)`.
3. Через минуту страница будет по адресу `https://oletol.github.io/shadow/`.

Открывать `index.html` двойным щелчком нельзя: браузер не даст загрузить `phrases.json` и запустить модели. Для проверки на компьютере: `python3 -m http.server 8000` в папке проекта и адрес `http://localhost:8000`.

## Встраивание в Moodle

Через ресурс «Страница» или «Пояснение» в режиме HTML:

```html
<iframe src="https://oletol.github.io/shadow/" width="100%" height="1400"
        allow="microphone; autoplay; fullscreen" style="border:0"></iframe>
```

Атрибут `allow="microphone"` обязателен, иначе запись внутри Moodle не заработает.

## Как добавить или исправить фразы

Редактируйте `data/phrases.json`. Текст фразы должен совпадать с аудио слово в слово: по нему строится выравнивание. Если не совпадает, под мелодией появится строка «Teacher check» с тем, что на самом деле слышит распознаватель. Сейчас стоит проверить две фразы, у которых название файла отличается от текста: `Had to speak.mp3` («I'd have to speak Shakespeare») и `try and explain as much.mp3` («I'll try and explain as»).

Цифры можно писать словами или числом (40 превратится в forty).

## Строгость

`"strictness"` в `phrases.json` – значение по умолчанию: `lenient`, `standard`, `strict`. Студент может переключить её внизу страницы. При `strict` отклонение мелодии в 2 полутона уже даёт около половины баллов; это ближе к требованию «точно как у диктора», но для начинающих может быть слишком жёстко.

## Модели

При первом запуске браузер скачивает около 230 МБ (wav2vec2 – 95 МБ, Whisper base.en – около 136 МБ) и потом хранит их в кэше. Если нужно легче, замените `"recognition"` на `"Xenova/whisper-tiny.en"`. Если huggingface.co медленно открывается, в поле `"host"` можно указать зеркало, например `"https://hf-mirror.com/"`.

Пока модели скачиваются или если они недоступны, интонация и темп всё равно сравниваются, а по словам результатов не будет.

## Ограничения

Оценка автоматическая и приблизительная. Модель произношения обучена на носителях американского и британского английского и оценивает буквы, а не фонемы, поэтому её вердикт по отдельному звуку – подсказка, а не диагноз. Для записи нужны HTTPS и тихое помещение; при режиме «Play the speaker while I record» лучше надеть наушники.
